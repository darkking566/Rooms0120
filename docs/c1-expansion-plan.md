## 2. 整體結構與路線圖

遊戲裡把這幾篇串成一張可探索的圖。串聯的方式是**本遊戲的原創設計**（原文沒有寫它們彼此如何連接，樞紐頁只說各疊加層級有自己的入口）。

```
                         Level 0（既有）
                  ┌───────────┴───────────┐
          紙箱（報告 I）            宏蟲洞（報告 V）
                  │                       │
                  ▼                       ▼
        ┌─── C-1「偏路」 ───┐         Level 0.4「碾城」
        │   （乾淨的房間）   │         （絕路層：沒有出口）
        │                   │
   窗戶 │       鏡子 + 龍鱗 │      盡頭的門
        ▼                   ▼             ▼
  C-1「東舟市」  ─龍鱗信物→  C-1「驤亭」   C-2（只做門與結局，不實作）
  （報告 II）    （報告 III）
        │
   東南 7.9 km
        ▼
  C-1「俄刻阿諾斯號」
  （報告 IV）
```

**主要路線（建議給玩家的順序）：** Level 0 → 紙箱 → 偏路 → 窗戶 → 東舟市 → 取得龍鱗 → 回偏路 → 鏡子 → 驤亭。俄刻阿諾斯號是東舟市的支線。Level 0.4 是獨立的絕路分支。

**所有 C-1 疊加層都可以走回頭路到偏路，再回 Level 0。** 只有 0.4 例外。

## 4. 各層級詳細設計

### 4.A　C-1「偏路」（報告 I）

**定位：** 最小、最安靜、最容易實作。恐怖來自「太乾淨」與「什麼都沒有」。先做這個。

**原文事實：**
- 無限延伸的室內空間：木地板、瓷磚牆、隨機分布的門窗，少數長椅與鏡子。
- 一切反常地一塵不染，沒有污垢或灰塵。
- 沒有明確用途，非線性，格局會變，繪製地圖沒有意義。
- 從未出現可用物品。
- 可能是 Level I 群與 C 群之間的普通連接層。
- 沒有確認的實體。腳註：遠處有重物落地的聲音，找不到來源，可能是未知實體，也可能是幻覺。其餘時間完全寂靜。
- 入口：從 Level 0 切出有機率到達；Level 0 裡的紙箱，走進去即可。
- 出口：走得夠遠，可能出現通往 Level C-2 的門，不保證有；在入口處反覆切出，可能回到 Level 0。

**場景表（5 個）：**

| 場景 ID | 標題 | 內容 |
| --- | --- | --- |
| `c1_entry` | 乾淨的房間 | 從紙箱掉出來的地方。木地板、白瓷磚牆、一張長椅、一面窗。身後是那個紙箱（放大的、從內側看的紙箱底，可以爬回去）。第一次進入說明「這裡沒有灰塵，連你的腳印都沒有」 |
| `c1_hall` | 無盡的長廊 | 兩側有門、有窗、有鏡子，排列隨機。**每次進入隨機重排**（見下方機制） |
| `c1_bench` | 長椅之間 | 整排長椅，每張都一模一樣。坐下休息可回復少量清醒度（見下方） |
| `c1_mirror` | 鏡廳 | 一整面牆的鏡子。對應第 4.C 節的驤亭入口 |
| `c1_door` | 盡頭的門 | 走滿規定步數後才會出現。門牌寫著「C-2」。三個選擇：開門、折返、窗戶 |

**機制：**

1. **格局重排（對應「非線性、格局會變」）。**
   - 在 `s.c1` 存一個 `{ steps, seed }`。每次 `go('c1_hall')` 時用新的 seed 決定三扇門的順序與位置。
   - 沿用 Level 0 隔間迷宮的「三個一模一樣的出口」手法（搜尋 `l0_maze`）。
   - **不要做成猜謎陷阱。** 這一層原文難度是 0，答錯只該讓你多走幾步，不該讓你重來。
2. **步數與門。** 玩家在 `c1_hall` 與 `c1_bench` 之間移動累計 `steps`。`steps >= 8` 時，`c1_hall` 的盡頭才出現 `c1_door`。數字 8 是起始值，可調。
3. **重物落地聲（對應腳註）。**
   - 在 `update` 裡每隔隨機 12 到 25 秒呼叫 `sound.sfx('bang')`（`audio.js` 已有 `bang`），並讓畫面輕微震動一下（參考 `shake` 寫法）。
   - **永遠不要畫出聲音的來源。** 這是這一層的核心：原文明確說找不到來源。
   - 在攝影機觀景窗下也看不到任何東西（`viewMsg`：「觀景窗裡什麼也沒有。聲音還是來了。」）。
4. **長椅休息。** 在 `c1_bench` 點長椅「坐下」：清醒度 +8，每個存檔一次（`once`）。理由：這一層沒有物資，需要一個回復點，否則步數限制太緊。
5. **鏡子（原創驚嚇，標為原創）。** 第一次在 `c1_mirror` 走近時，倒影慢半拍才動。只做一次，沒有傷害，只扣 3 點清醒度。
6. **沒有物品。** 這一層任何熱點都不給予物品。這是原文設定，也是它的特色。唯一例外是玩家自己帶進來的東西。
7. **一塵不染的演出：**
   - 畫面用高亮、低對比的冷白，不要霧氣、不要髒污紋理。
   - 玩家的腳印：每走一步在地板上留下淡淡的腳印，下一個場景消失。（原創，呼應「連腳印都留不下」。）

**出口：**
- `c1_entry` 的紙箱：回 Level 0。
- `c1_hall` 的窗戶（`steps >= 3` 後可開）：通往東舟市郊外（見 4.B）。這是本遊戲的原創連接。
- `c1_mirror`：持有龍鱗信物時通往驤亭（見 4.C）。
- `c1_door`：開門進入 C-2，**只做一個短結局，不實作 C-2**（見第 7 節 `c2_door`）。

**Level 0 的入口：**
- 在 Level 0 的**一個**既有場景加上紙箱熱點。建議 `l0_dry`（乾燥的走廊），沒有重要劇情；若不合適可選別處，但**不可放在主線必經場景的重要位置，也不可改動現有熱點的順序**。
- 肉眼看只是一個空紙箱。**這個設計用到攝影機：** 舉起攝影機看紙箱，箱底顯示一片乾淨的白瓷磚（`viewMsg`），暗示它通向某處。
- 點擊跳入 → `go('c1_entry')`。進入時寫入進入檢查點。

**音效（`audio.js`）：** 新增 `lv === 'C1'` 分支。幾乎靜音：一條極低的 sine（約 45 Hz，增益 0.01）加上極淡的白噪音。**不要用 Level 0 的日光燈嗡嗡聲。** 原文強調這一層完全寂靜。

### 4.B　C-1「東舟市」（報告 II）

**定位：** 敘事型層級，以「採訪三個被收容的實體」為主，探索量中等。

**原文事實（務必核對）：**
- 廣袤無垠的疆域：平原、山川、江河。曾有懸浮島、不倒的岩群、逆流瀑布，**現已消失**。
- **東舟市**是核心，約 510 平方公里，常駐人口嚴格控制在約 12,000。
- 建築不是人工建造，而是從地底「生長」出來（「擴城現象」）。新建築多為毛坯。內部潔淨，外部泥土在生長過程中脫落。擴城早期頻繁，之後明顯減緩。
- 由 M.E.G.（探險者總署）、後室機器人科技、E.P.B.（正電子粒子科技有限公司）三方聯合占據。
- 設施：三合研究院（市中央）、M.E.G. C-Lambda 基地（東，M.E.G. 在 C 層群的第十一個主要基地）、撒加利工廠（西，約 7.4 平方公里，由第 19 次擴城的巨型建築改造）、珀爾修斯實驗室（北，E.P.B.，信息僅對 γ 級權限開放）、新紀花園（南，生活區）、紅星建築隊第 21 至 23 支隊、02 區與 03 區（軍事基地，03 區設有艾亞哥斯收容管理局 ACMA）。
- 屬性：無害波動，難度 3（局部安全、穩定、高危實體出沒）。
- 出入口不對外公開，由三方封鎖。另有通往 C-100 的特殊出口：木屋內獨處 5 分鐘（M.E.G. 的「破門項目」）。

**ACMA 收容的實體（原文）：**

| 編號 | 原文描述 |
| --- | --- |
| E-024 | 約 0.9 米、像臃腫綿羊，頭頂原有巨角，據稱曾是 20 米長的巨獸。吞食垃圾，後肢被咬斷後再生，不斷縮小，最終可能消失。自稱「饕餮」。安保人員 Sampson Adams |
| E-013 | 紅髮少年外貌，腰圍白袍。自稱火神「祝融」，傲慢，以未知手段毀壞錄音筆。持續縮小、變年輕。坐騎是兩條赤龍。安保人員平井蒼生 |

   - **同一個存檔內每個子空間只會被插入一次**，全部經歷後，第四扇門才出現，通往 `c1s_sea`，再通往 `c1s_h`。**不要做成純隨機導致玩家刷不到。**
2. **屍鼠堆（`c1s_metro`）。** 原文只提到屍鼠，沒有具體行為。遊戲裡：踩過屍鼠堆（點擊錯的熱點）清醒度 -8，並設旗標 `c1s_plague`（疫疾）。
3. **疫疾（`c1s_plague`）。** 原文：落君患疫疾，經治療康復。遊戲裡：疫疾每步多扣 1 點清醒度，直到使用杏仁水或在 `c1s_town` 的電話亭拿到的藥。**需要有至少一個治療來源**（電話亭必給一個杏仁水），否則玩家會卡死。
4. **電話亭（`c1s_town`）。** 原文：電話亭內有隨機物品。遊戲裡：每個存檔第一次點擊給 `almond`（杏仁水），之後只給文字描述。**不要做真正的隨機**，保持可預測，避免卡關。
5. **管家 1399（`c1s_h`）。** 靜態 NPC。點擊「對話」：
   - 一般問題 → 「無可奉告。」
   - 問「至慧」→ 給一小段背景筆記 `n_c1s_butler`。
   - 問「落君」→ 管家說他推測倖存者在躲避外人（原文）。
   - **永遠不說口令。**
6. **落君（`c1s_hideout`）。** 她對管家不信任。這是一個**救援互動**：玩家把管家留在原地（不帶他），單獨與落君對話，她才願意跟你走。
   - 原文：落君拒絕說出口令、同伴死於能源庫 1063。這些用筆記呈現（`n_c1s_junjun`）。
   - 如果玩家先把管家帶到落君面前，她會拒絕開口（旗標 `c1s_butler_near`），需要先離開再回來。
7. **子空間消失（結局動作）。** 玩家救出落君並走出去時，沿途子空間入口一個個熄滅（對應原文：落君抵達東舟市第 8 日，子空間入口突然全部消失）。畫面上門框一個個變黑。

**出口：** 回東舟市郊外（`c1e_trek`）。完成救援後，玩家**可以選擇帶落君回去**（`c1s_rescued` 旗標），抵達東舟市時有一段文字（落君被送去醫療部門，原文）。這是這條線的完成點。

### 4.E　Level 0.4「碾城」（報告 V）

**定位：** 結局型層級。**沒有出口**，進去就回不來，這是原文設定。

**原文事實（務必核對）：**
- Level 0 的子層級，宜居。局部安全、局部穩定、局部實體絕跡。
- 環境：名為「碾城」的現代都市，街巷縱橫，樓房密集，夾雜粗野主義建築。供水與排汙基本正常，電力沿環線分布，由內環向外環遞減，內環之外常有波動。層裂變後天空呈深紅色。
- **入口：** 穿過 Level 0 內的「宏蟲洞」。圓柱形空洞，入口半徑約 4.2 m，內部缺乏光照，洞口與側壁模糊失真，翻湧黑紫色彩，**觸之刺痛**。穿越其出口端的星空帷幕即進入。直接穿越帷幕會當即切出到 0.4。
- **出口：** 無路可回，是「絕路層」。
- **層裂變：** 每約 168 小時（7 日）發生一次，持續約 2 分鐘。除碾城市區外，其餘區域的物質構成、自然環境、物品分布、實體種類數量都會劇變，常出現多種實體與少量物資。成因未知。天空在現象前後數小時內變深紅色並保持。
- 碾城大部分建築與內部配置由層級自行形成。與 Level 38 的重塑特性似屬同類。
- 勢力：先驅（盤踞內環，實力最強資源最豐；鐵穹區是內環「七大區」之一，由「穹頂系統」全天護衛，主要負責科研）、獵手（分散居住在尉遲大道兩側；尉遲大道在中環，全長約 21 km；紅殿是猎手公會總部；寶庫 Tower 據稱與大道末端相連，用於交付物資，內環景象僅在交付時段出現）、浪人（流浪者；「狼領」名稱有歧義：先驅用它指浪人首領，浪人用它指碾城市區外的全部區域）。
- 先驅成員已證實 0.4 是絕路層。龍曆 2022 年 1 月 24 日起發生一系列事件，**導致正文大部分內容已不再適用**，詳情在附錄集（頁面連到 `/weed-toc`）。

> **注意：** 頁面自己說正文大部分內容已不再適用。請**一併核對 `/weed-toc` 附錄**（https://backrooms-wiki-cn.wikidot.com/weed-toc），決定遊戲要採用「事件前」還是「事件後」的碾城。**建議用事件前的狀態**（原文正文），並在 README 註明。如果你核對後認為附錄更適合，請改版並告訴使用者。

   - 進入後所有場景的 `back` 熱點都不可用（沒有出口）。
2. **層裂變（核心機制，縮短時間）。**
   - 原文：每 168 小時發生一次，持續約 2 分鐘。遊戲把它**壓縮**：每累計 **90 秒的場景時間**（`update` 的 `dt`）觸發一次，持續 **6 秒**。
   - 這兩個數字是起始值，請用試玩調整。
   - 觸發時：天空變深紅色並保持；**只有 `l04_wolf` 的畫面與熱點改變**（物資、實體、地貌）。其他場景（市區）**不受影響**，對應原文「除碾城市區外」。
   - `l04_wolf` 在每次層裂變後重新生成：用 seed 決定出現「一個物資箱」或「一個遠處的實體剪影」。
   - **物資有限。** 整個 0.4 最多提供 3 份補給（`almond`、`bar`、`can` 各一），不夠撐到永遠。這是絕路層的核心壓力。
3. **三個勢力（原創的互動，原文只描述了勢力本身）。**
   - 先驅、獵手、浪人各有一個據點場景（鐵穹區外、紅殿、狼領）。
   - 玩家可以在每個據點「搭話」，用筆記呈現各自的立場。**不做加入勢力的機制**，只做資訊。
   - 搭話的重點：先驅證實 0.4 是絕路層。
4. **絕路。** 沒有任何出口熱點。玩家能做的是：探索、拿到有限物資、讀完所有筆記，然後選擇「在這裡待下去」。
5. **宏蟲洞外的伏筆。** 在 Level 0 側，宏蟲洞旁邊放一張**紙條**（`n04_warn`，原創，J.H. 風格）：警告「這個洞只進不出」。

**結局：** `dead_end`（絕路結局）。**觸發條件：** 玩家在 `l04_inner` 的最終熱點選擇「留下」，或清醒度歸零（既有 `lost` 結局）。結局文字寫「你找過了每一個出口。沒有。這座城的燈亮著，電力由內向外遞減，你的也是。」之類，以平靜、不戲劇化的語氣收尾。

**音效：** 新增 `lv === '0.4'`：都市底噪（white noise lowpass 約 300 Hz，增益 0.05）+ 遠處電力的低頻嗡鳴（sine 約 50 Hz）。層裂變時加一個上升的音（`sound.sfx('surge')`，既有）。

## 11. 原文 vs. 原創（寫進 README 用）

**來自原文（改編）：**
- 偏路：乾淨的室內空間、沒有物品、格局變化、重物落地聲、紙箱入口、通往 C-2 的門。
- 東舟市：三方共管、擴城現象、510 平方公里與約 12,000 人、ACMA 與 024 / 013 / 002 / 025、時駒與衍射光柵、002 只對篤信者顯現。
- 驤亭：平原與齊尾雜草、龍血族與其成員、約塔破層與裂隙、信物通行、龍血威懾與人類免疫、阿爾法之眼（K014、23 次）、尊父對「箱庭」與「主角」的看法。
- 方舟：窗戶深藍溫熱、子空間插入、管家 1399、落君、屍鼠與疫疾、子空間類型、口令不被說出。
- 0.4：碾城、宏蟲洞（半徑 4.2 m）、層裂變週期、絕路層、三個勢力。

**本遊戲原創（必須標明）：**
- 五篇之間的連接方式（窗戶、龍鱗、鏡子、trek）。
- 013 賞賜龍鱗。
- 玩家身分（訪客、不是時駒）、錄音筆機制。
- 002 的「停留 5 秒」機制。
- 阿爾法之眼的三個入夢情景與「干涉」玩法。
- `torn_script`、`dead_end`、`c2_door` 三個結局的具體演出。
- 偏路的腳印與鏡子的倒影驚嚇。
- 層裂變的時間壓縮與物資數量。
- 所有 J.H. 筆記與所有謎題文字。
