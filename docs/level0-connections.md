## 從 Level 0 能去哪裡（出口）

| 去處 | 方法 | 狀態 | 出處 |
| --- | --- | --- | --- |
| **Level 1** | 找到一面閃爍的牆，穿過去。現行版沒有列出其他出口。 | 現行 | [Level 0 - "Threshold"](https://backrooms-wiki.wikidot.com/level-0) |
| Level 1 | 「只能靠 noclip 離開，而且一定會進入 Level 1。」 | 舊版 | [(ARCHIVED) Level 0 - "Tutorial Level"](https://backrooms-wiki.wikidot.com/archived:level-0-2020) |
| **Manila Room**（馬尼拉房間） | 很難找到的小房間。舊版說要朝同一方向走非常遠才可能遇到；它是死路，是倖存者的會合點，放著 M.E.G. 文件。 | 現行（頁面改寫中） | [Level 0](https://backrooms-wiki.wikidot.com/level-0)、[manila room](https://backrooms-wiki.wikidot.com/manila-room) |
| **Red Rooms**（紅房間） | 只能從 Level 0 進入：轉過某個轉角時隨機出現，無法預測位置。進去之後「推定沒有出口」。 | 現行 | [Red Rooms](https://backrooms-wiki.wikidot.com/red-rooms) |
| **Level 0.2 "Remodeled Mess"** | 燈管的嗡嗡聲變小、地毯變乾、房間開始像施工中時，有機會找到一扇門。 | 現行 | [Level 0.2](https://backrooms-wiki.wikidot.com/level-0-2) |
| **Level 0.7 "The Reminiscence District"** | Level 0 的子層級，是保存「後室歷代改版」的時間泡。頁面沒有寫怎麼進去；離開只能「轉身退出去」。 | 現行 | [Level 0.7](https://backrooms-wiki.wikidot.com/level-0-7) |

現行 Level 0 頁面描述的區域變化（不是獨立樓層）：

- 停電區（Blackout Zones）：整片沒有燈、而且一直在變動。
- 柱子區、拱門區、坑洞區：反覆出現的建築變化。
- Base Alpha：頁面中有一段倖存者證詞提到它，說從 Level 0 出來的人常常是半譫妄、嚴重脫水又飢餓的。

頁面也寫「不確定 Level 0 是否存在實體」。

- Level 601 只在一句比喻裡提到 Level 0，不是通道。
- Level 0.1、0.5、0.11 等子層級的入口說法，來自 Fandom 等其他 wiki 或遊戲版本。這些說法互相矛盾，Wikidot 上也沒找到對應的現行頁面，所以不列入。

## 給 ROOMS0120 的設計提醒

1. **Level 0 的正規出口只有 Level 1。**現在遊戲的「閃爍的牆 → Level 1」完全符合現行設定。如果要加支線出口，用子層級（0.2、0.7）或特殊房間比較安全，不要讓 Level 0 直接通往別的主層級。
2. **回到 Level 0 的路，都來自「比較遠」的樓層**（21、283，以及已刪減的 92、124）。現行 Level 1 和 Level 2 都沒有寫可以回到 Level 0。如果遊戲想做「被送回 Level 0」的情節（例如迷失結局或循環），就得設計成異常事件，而不是一般通道。
3. **Manila Room 是孤立效應唯一的例外**，是唯一能遇到別人的地方。這很適合 J.H. 的劇情：例如讓玩家在那裡第一次「遇見」J.H.，或者確認根本沒有別人。注意它目前正在改寫，細節可能會變。
4. **Red Rooms 是死路。**可以當作陷阱或壞結局：轉角後隨機出現、無線電訊號逐漸消失、地毯長霉菇、有計數刻痕的圖。現行頁面明確說進去後推定無法離開。
5. **Level 0.2 的進入徵兆很適合點擊式解謎**：嗡嗡聲變小、地毯變乾、房間像施工中。這可以當作「環境逐漸變化」的找路謎題，和 Level 1 → Level 2 的平滑過渡相呼應。
6. **Level 0.7 是保存歷代後室版本的時間泡。**它很適合用來回收遊戲本身的「褪色的房間」概念。但目前褪色的房間是原創設定，跟 0.7 沒有關係；如果要掛鉤，要另外處理授權標示。
7. **停電區**可以讓手電筒在 Level 1 之前就派上用場，或者拿來搭配觀景窗做黑暗中的找路，因為現行設定沒有說 Level 0 有實體。
8. **Level 0 沒有確認存在的實體。**之前設計時刻意不讓笑魔出現在 Level 0，這點要繼續保持。
