| 去處 | 方法 | 狀態 | 出處 |
| --- | --- | --- | --- |
| **Level 1** | 找到一面閃爍的牆，穿過去。現行版沒有列出其他出口。 | 現行 | [Level 0 - "Threshold"](https://backrooms-wiki.wikidot.com/level-0) |
| Level 1 | 「只能靠 noclip 離開，而且一定會進入 Level 1。」 | 舊版 | [(ARCHIVED) Level 0 - "Tutorial Level"](https://backrooms-wiki.wikidot.com/archived:level-0-2020) |
| **Manila Room**（馬尼拉房間） | 很難找到的小房間。舊版說要朝同一方向走非常遠才可能遇到；它是死路，是倖存者的會合點，放著 M.E.G. 文件。 | 現行（頁面改寫中） | [Level 0](https://backrooms-wiki.wikidot.com/level-0)、[manila room](https://backrooms-wiki.wikidot.com/manila-room) |
| **Red Rooms**（紅房間） | 只能從 Level 0 進入：轉過某個轉角時隨機出現，無法預測位置。進去之後「推定沒有出口」。 | 現行 | [Red Rooms](https://backrooms-wiki.wikidot.com/red-rooms) |
| **Level 0.2 "Remodeled Mess"** | 燈管的嗡嗡聲變小、地毯變乾、房間開始像施工中時，有機會找到一扇門。（**遊戲已做**：濕透的房間 → 乾燥的走廊 → `l02_room`） | 現行 | [Level 0.2](https://backrooms-wiki.wikidot.com/level-0-2) |
| **Level 0.7 "The Reminiscence District"** | Level 0 的子層級，是保存「後室歷代改版」的時間泡。頁面沒有寫怎麼進去；離開只能「轉身退出去」。 | 現行 | [Level 0.7](https://backrooms-wiki.wikidot.com/level-0-7) |

現行 Level 0 頁面描述的區域變化（不是獨立樓層）：

- 停電區（Blackout Zones）：整片沒有燈、而且一直在變動。
- 柱子區、拱門區、坑洞區：反覆出現的建築變化。
- Base Alpha：頁面中有一段倖存者證詞提到它，說從 Level 0 出來的人常常是半譫妄、嚴重脫水又飢餓的。

頁面也寫「不確定 Level 0 是否存在實體」。

### 四個子層級（中文 Wiki）的進入方式

查詢日期：2026-11-13。遊戲據此把入口分散在 Level 0 各處，不再集中在同一個房間。

| 子層級 | 原文怎麼進去 | 遊戲的做法 |
| --- | --- | --- |
| [0.1 天頂站](https://backrooms-wiki-cn.wikidot.com/level-0-1) | 「只須直接走入相應的區域即可」，但 Level 0 太大，幾乎不可能遇到；B.N.T.G. 掌握一種可靠的方法。出口：返回 Level 0，或隨機切出到 Level 1。 | 柱子房間右牆的門洞 → `l0_annex`：跟著 B.N.T.G. 噴漆箭頭連走四次，走錯一次就從頭找 |
| [0.3 冰室](https://backrooms-wiki-cn.wikidot.com/level-0-3) | 沒有寫入口。外觀幾乎和 Level 0 一樣，只是到處都是冰；通風口不停吹冷氣。 | 第一條走廊天花板旁的冷風格柵 → 循地毯上的霜走 |
| [0.5 淵閉療舍](https://backrooms-wiki-cn.wikidot.com/level-0-5) | 敘述者在 Level 0 的熄燈區被熟悉的嗡鳴聲引導，「找到一段樓梯往下走」。第 9 天找到金屬格柵樓梯通往 Level 1。 | 停電區走對第一步後，腳邊出現往下的台階 |
| [0.7 憶域](https://backrooms-wiki-cn.wikidot.com/level-0-7) | 沒有寫入口。是保存歷代後室的時間泡；「除了原路折返之外，沒有固定的出口」。 | 褪色的房間（本作 Level 0 最舊的地方）右牆的門洞，回程也走回這裡 |

查過但**不採用**的：

- Level 601 只在一句比喻裡提到 Level 0，不是通道。
- Level 0.1、0.5、0.11 等子層級的入口說法，來自 Fandom 等其他 wiki 或遊戲版本。這些說法互相矛盾，Wikidot 上也沒找到對應的現行頁面，所以不列入。

## 給 ROOMS0120 的設計提醒

1. **Level 0 的正規出口只有 Level 1。**現在遊戲的「閃爍的牆 → Level 1」完全符合現行設定。如果要加支線出口，用子層級（0.2、0.7）或特殊房間比較安全，不要讓 Level 0 直接通往別的主層級。
2. **回到 Level 0 的路，都來自「比較遠」的樓層**（21、283，以及已刪減的 92、124）。現行 Level 1 和 Level 2 都沒有寫可以回到 Level 0。如果遊戲想做「被送回 Level 0」的情節（例如迷失結局或循環），就得設計成異常事件，而不是一般通道。
3. **Manila Room 是孤立效應唯一的例外**，是唯一能遇到別人的地方。這很適合 J.H. 的劇情：例如讓玩家在那裡第一次「遇見」J.H.，或者確認根本沒有別人。注意它目前正在改寫，細節可能會變。
4. **Red Rooms 是死路。**可以當作陷阱或壞結局：轉角後隨機出現、無線電訊號逐漸消失、地毯長霉菇、有計數刻痕的圖。現行頁面明確說進去後推定無法離開。
5. **Level 0.2 的進入徵兆很適合點擊式解謎**：嗡嗡聲變小、地毯變乾、房間像施工中。這可以當作「環境逐漸變化」的找路謎題，和 Level 1 → Level 2 的平滑過渡相呼應。
6. **Level 0.7 是保存歷代後室版本的時間泡。**它很適合用來回收遊戲本身的「褪色的房間」概念。但目前褪色的房間是原創設定，跟 0.7 沒有關係；如果要掛鉤，要另外處理授權標示。
7. **停電區**可以讓手電筒在 Level 1 之前就派上用場，或者拿來搭配觀景窗做黑暗中的找路，因為現行設定沒有說 Level 0 有實體。
8. **Level 0 沒有確認存在的實體。**之前設計時刻意不讓笑魔出現在 Level 0，這點要繼續保持。

使用上述任何設定時，記得在 README 的 Credits 加上對應頁面的標題與作者（CC BY-SA 3.0 要求）。

## 現行 Level 0 頁面有、而遊戲還沒有的元素

對照 [Level 0 - "Threshold"](https://backrooms-wiki.wikidot.com/level-0)（DivineAtlas、DrAkimoto、Robert Goerman 改寫）的內容整理。

| 元素 | 頁面描述 | 遊戲狀態 |
| --- | --- | --- |
| 拱門區（Arches） | 淡色牆面上開著拱形門洞，多在死路或過渡房間；地毯深而濕；是最穩定的區域，可短暫休息。 | **已做**：`l0_arches`，可休息、回復清醒度並記錄檢查點 |
| 坑洞區（Holes） | 格狀排列的漆黑坑洞，光只照得到幾呎；沒有人回報摔下去還活著。 | **已做**：`l0_holes`，踩空即墜落結局 |
| 停電區（Blackout Zones） | 沒有燈、非常安靜、牆面粗糙，地面凹陷積著到腳踝的液體，格局在黑暗中變動；朝第一道光衝，或循著（會移動的）嗡嗡聲走。 | **已做**：`l0_blackout` |
| 紅房間（Red Rooms） | 閉環區域，幾乎不可能逃出；徵兆是偏紅、地毯厚而黏、剝落壁紙下露出深紅色漆；應立刻回頭。 | **已做**：`l0_red`＋紅房間結局 |
| 馬尼拉房間 | 孤立效應唯一的例外，人能互相看見；極難找到。 | **已做**：`l0_manila` |
| 嗡嗡聲暴增 | 音量會無預警暴漲，長期暴露會傷聽力；摀住耳朵繼續走。 | **已做**：隨機事件 |
| 黑影與被注視感 | 有人宣稱看到黑影跟蹤，未證實。 | **已做**：走廊盡頭時隱時現的黑影 |
| 地毯中的液體 | 鹽水、半鹹水、Liquid Pain、福馬林、含 DNA 的泥漿；Level 0 的杏仁水被污染，地毯不能吃。 | **已做**：起始房間地毯上撿到的是「濕掉的杏仁水」，喝了會傷清醒度 |
| 越待越多的異常 | 待得越久，奇怪的建築越常出現。 | 部分：走廊繞越多圈，越容易出現紅房間的轉角 |
| 樓梯 | 「房間、走廊和樓梯」。 | **已做**：`l0_stairs`，連接拱門區與坑洞區 |
| 求生技巧 | 睡覺時面向前進方向、左手摸牆、在柱子區選定方向就別改。 | 寫進 M.E.G. 的文件 |
| 脫水與飢餓 | 最常見的死因。 | **已做**：水分與飽足兩個數值，歸零時加速消耗清醒度，並有脫水／飢餓結局 |

遊戲中的馬尼拉房間、停電區找路方式、紅房間結局的劇情與謎題皆為原創，只借用上述頁面的區域概念。
